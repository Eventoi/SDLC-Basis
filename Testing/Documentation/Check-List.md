# Чек-лист
Список проверок
> [!NOTE]
> Существуют два типа:
> 1. Краткий. Описание в виде связки глагол + существительное. Без ожидаемого результата. Никому, кроме вас непонятен
> 2. Расширенный. Описание в виде связки глагол + существительное. С ожидаемым результатом и кратким описанием логики. Более доходчивый (даже для самого себя спустя много времени)
