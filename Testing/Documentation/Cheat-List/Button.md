### ОБЩЕЕ

    ДИЗАЙН:
        * Цвет, размер, расположение, шрифт и т.п.
        * Active, hover, pressed, disabled

    ДЕЙСТВИЕ:
        * При наведении курсор мыши меняется на pointer

### КНОПКА

    ДИЗАЙН:
        * Анимация/лоадер после нажатия
        * Текст соответствует логике действия: "Сохранить" сохраняет, "Закрыть" закрывает и т.п.

    СОСТОЯНИЕ:
        * По умолчанию: active/disabled

### КРЕСТИК

    ДЕЙСТВИЕ:
        * Информер > удаляет прикрепленные данные
        * Поле ввода > очищает поле от введенных данных
        * Модальное окно > закрытие окна
        * Форма
            > Вызов модального окна для предложения сохранения данных, если:
                - Сохранение данных предусмотрено в самой форме
                - Данные не были сохранены
            > Закрытие окна, если:
                - Сохранение данных не предусмотрено в самой форме
                - Данные были сохранены

### РАДИОКНОПКИ, СВИТЧЕРЫ/ТОГГЛЫ, ЧЕКБОКСЫ

    ДИЗАЙН:
        * Справа/слева от текста

    СОСТОЯНИЕ:
        * По умолчанию: вкл/выкл

    ДЕЙСТВИЕ:
        * Появление поля(-ей) для ввода данных при включении
            > Cохранение введенных данных в поле(-ях) после выкл/вкл

### ГОЛОСОВОЙ ВВОД

    ДЕЙСТВИЕ:
        * При надиктовывании > текст появляется в поле (ввод осуществляется на языке, который установлен в браузере)
