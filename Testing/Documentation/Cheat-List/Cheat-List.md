# Чит-лист
Список универсальных проверок (одних и тех же действий над элементами интерфейса)

> [!NOTE]
> Чит-лист статичен и подходит всем:
> * аналитику при описании элементов во время создания постановки
> * дизайнеру, после этапа прототипирования
> * разработчику, чтобы не забыл сверстать все элементы
> * тестировщику, чтобы не забыл проверить все элементы
