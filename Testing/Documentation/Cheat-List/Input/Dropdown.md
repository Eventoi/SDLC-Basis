### ОБЩЕЕ

	ДЕЙСТВИЕ:
        * При наведении на стрелку курсор мыши меняется на pointer
            - При нажатии на стрелку > выпадает список
            - При повторном нажатии > список закрывается
        * Список скроллится вверх/вниз колесиком мыши
        * Список листается клавиатурными стрелками с появлением скроллбара и выделением текущей опции
        * Ввод клавиатурных сокращений:
            - стрелки вниз/вверх
                > открытие/закрытие списка
                > листание вверх/вниз
