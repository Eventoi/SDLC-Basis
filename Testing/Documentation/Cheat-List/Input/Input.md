### ОБЩЕЕ

    ДИЗАЙН:
        * Цвет, размер, расположение, шрифт и т.п.
        * Hover, disabled, failed, unfocused с текстом

    СОСТОЯНИЕ:
        * По умолчанию: active/disabled, fill/empty
        * Обязательно/не обязательно
            - При обязательном > вывод ошибки при сохранении пустого поля/при переключении на другое поле

    ДЕЙСТВИЕ:
        * При наведении курсор мыши меняется на text
        * При нажатии курсор text устанавливается в поле
        * Ввод cпецсимволов/альт-кодов
        * Ввод и вставка (Ctrl + V) минимального/максимального количества символов с пробелами и без
            - При ограничении кол-ва символов > вывод ошибки с количеством разрешенных символов
        * Ввод пробелов:
            - Перед/после символов > отбрасываются
            - Внутри, между символов > корректно обрабатываются
            - Множество одних пробелов > выводится ошибка/отбрасываются
        * Ввод клавиатурных сокращений: Backspace, Delete, Home, End; зажать Shift и напечатать символы; Shift + Стрелки вправо/влево/Home/End; Ctrl + Стрелки вправо/влево; Ctrl + C/X/V/Z

### ТЕКСТОВЫЙ

    ДЕЙСТВИЕ:
        * Ввод на кириллице/латинице: регистр букв верхний/нижний/комбинированный
        * Ввод чисел > выдается ошибка/не вводятся
        * Обсценная лексика (мат)

### ЧИСЛОВОЙ

    ДЕЙСТВИЕ:
        * Ввод 0
        * Ввод отрицательных чисел
        * Ввод продвинутых чисел:
            - Экспоненциальное (123e-5)
            - Двоичное (0b1111)
            - Восьмеричное (0o17)
            - Шестнадцатеричное (0xFF)
        * Ввод дробных чисел с разным разделителем (0.0001; 0,0001)
        * Ввод чисел с запятыми, точками, пробелами (1,000,000; 1.000.000; 1 000 000)
        * Ввод текста > выдается ошибка/не вводится

### ЛЭЙБЛ

    ДЕЙСТВИЕ:
        * При пустом поле находится внутри него
        * При установке курсора в поле, съезжает на верхнюю границу поля
        * При снятии фокуса с пустого поля, съезжает обратно внутрь поля
            - не накладывается на плейсхолдер
        * При заполненном поле и снятии фокуса с него, остаётся на верхней границе поля

### ПЛЕЙСХОЛДЕР

    ДЕЙСТВИЕ:
        * Исчезает при установке курсора в поле/вводе текста
